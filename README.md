# أداة استخراج اللون من الصور

## محتويات الملف المضغوط
- `index.html` — كود التطبيق الكامل باللغة العربية (RTL).
- `icon.svg` و `logo-transparent.png` — شعار الأرنبين (تركوازي ووردي) البسيط بخلفية شفافة.
- `icon-512.png` و `icon-192.png` و `apple-touch-icon.png` — أيقونات التطبيق للهاتف والمتصفح.
- `manifest.json` و `sw.js` — ملفات ربط الأيقونة وتثبيت التطبيق مباشرة من المتصفح (PWA).

## طريقة النشر على GitHub وتثبيت التطبيق
1. فك الضغط عن الملف، ثم ارفع جميع الملفات الموجودة بداخله مباشرة إلى المستودع (Repository) في **GitHub**.
2. من **Settings** > **Pages** اختر فرع `main` واضغط **Save**.
3. افتح رابط الموقع من المتصفح واضغط **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية** ليظهر التطبيق على جهازك بأيقونة الأرنبين.
